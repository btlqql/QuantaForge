# 交互 07：性能优化与结果边界

**用户目标**：优化壁仞GPU性能，并提高赛事性能材料的可信度。

**Agent行动**：审查旧基准后发现其仅覆盖4至20比特、重复3次且没有区分冷启动。实现Web启动阶段GPU预热，新增首次执行、稳定态中位数、P95、吞吐率、逐次样本和CPU/GPU完整状态差异；将正式规模扩展到26比特。进一步实测执行器复用、深纠缠线路和`complex64`参数，确认这些尝试在UnitaryLab 1.0壁仞后端上没有形成稳定速度优势。

**实测反馈**：Web新进程GPU预热2.908秒，最大解析误差2.980e-08；24比特最佳相对加速比0.604；26比特GPU中位耗时7.519秒，CPU/GPU状态差为0。完整正确性回归5.117秒通过，单元测试8/8通过。

**决策**：不声称不存在的GPU加速。将优化成果定义为首请求延迟消除、测试规模扩展、统计方法改进和可复核证据增强，并在报告中明确当前后端边界。
