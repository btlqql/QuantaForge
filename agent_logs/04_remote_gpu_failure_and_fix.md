# 交互记录 04：非交互 GPU 环境失败与修复

- 日期：2026-07-27
- 现象：本地单元测试通过，但远程正确性脚本提示 GPU 后端不可见。
- 排查：交互式示例能运行，非交互 SSH 进程没有加载 `brsw_set_env.sh` 导出的动态库环境；仅在已启动进程中修改 `LD_LIBRARY_PATH` 仍不足以加载后端。
- 修复：新增运行时环境检测；加载 SUPA 环境后重新执行 Python 入口，并在 CLI、Web、验证、基准脚本中统一调用。
- 复测：Bell、GHZ、Grover 的 CPU/GPU 快速套件全部通过，跨设备差为 0。
- 价值：记录并解决了真实部署兼容性，而不是只在开发机上声明可用。
