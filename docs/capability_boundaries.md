# 能力边界与风险控制

1. QuantaForge是量子模拟平台，不连接真实量子计算机。
2. 当前支持Bell、GHZ、Grover和QAOA MaxCut，不把未测试算法标记为可用。
3. Agent只生成结构化实验参数，不执行用户输入中的Shell或Python代码。
4. 状态矢量内存随量子比特指数增长，因此设置明确上限。
5. QAOA精确验证使用经典穷举，限制为10量子比特。
6. GPU加速效果取决于规模；小线路可能因启动开销慢于CPU。
7. GPU或验证失败时保留错误和部分结果，不生成虚假成功结论。
8. 开源算法实现明确标注来源，QuantaForge不主张第三方代码的原创权。
