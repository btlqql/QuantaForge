# 性能分析

## 测试设置

- 任务：4、8、12、16、20 量子比特 GHZ 状态矢量模拟。
- 设备：同一赛事节点上的 CPU 与 Biren106M。
- 重复：每种规模、每种设备 3 次，使用中位耗时。
- 正确性：每次比较解析 GHZ 概率分布。

## 结论

在当前“浅线路 + 最大 20 比特”的演示负载下，GPU 没有获得加速；CPU/GPU 比值为 0.056–0.112。原因是有效计算量很小，GPU 初始化、数据搬运和内核调度开销高于线路计算本身。

这个结果不应外推为“GPU 不适合量子模拟”。它说明性能判断必须绑定线路深度、状态规模、精度、批量方式和后端实现。QuantaForge 因此把 GPU 的首要价值定义为：真实后端支持、跨设备正确性验证以及为更大负载保留的执行能力；不会为了展示而选择性删除不利数据。

全部原始记录见 `reports/generated/performance/benchmark.csv` 和 `benchmark.json`，运行时设备快照见同目录 `brsmi.txt`。
