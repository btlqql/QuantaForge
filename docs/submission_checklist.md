## 参赛者需要在平台完成

1. 将含 `SKILL.md` 的作品压缩包上传到科学发现平台。
2. 在“我的 Skills / 科学工具”中打开作品详情并点击分享。
3. 复制生成的公开作品链接，粘贴到赛事提交页“作品链接”。
4. 把同一最终压缩包上传到“其他提交材料”。
5. 提交前从压缩包根目录确认可直接看到 `SKILL.md`，并确认分享链接在无登录窗口可打开。

不要把 GPU SSH 密码、临时账号或本地绝对路径写入公开材料。
