## 新建 Skill

- 上传文件：项目根目录 `SKILL.md`
- Skill 名称：`quantaforge`
- GitHub 仓库：`https://github.com/btlqql/QuantaForge`
- Skill 可见性：`公开`

Skill 描述（500 字以内）：

```text
QuantaForge 是面向量子模拟与算法演示的可验证实验 Skill。用户可用自然语言描述 Bell、GHZ、Grover 或 QAOA MaxCut 任务，系统将其转换为受约束的结构化实验协议，调用 UnitaryLab 在 CPU 或壁仞 GPU 上执行，并通过解析公式、经典穷举及跨设备对比独立验证结果。输出概率、误差、线路图、运行指标、日志和可复现报告。适用于量子计算教学、算法验证、GPU 后端演示与实验归档；不连接真实量子硬件，不执行任意用户代码。
```

学科建议按平台实际选项依次选择：

1. 优先：量子科学与技术 / 量子计算。
2. 若无上述选项：物理学。
3. 可附加：计算机科学与技术。

标签建议（最多 5 个，按平台可选项取最接近者）：

- 量子计算
- 量子算法
- GPU 加速
- 科学计算
- 智能体 / Agent

## 发布后

1. 打开“我的 Skills”或“科学工具广场”中的 QuantaForge。
2. 进入详情页，点击右上角“分享”。
3. 复制 `https://discovery.intern-ai.org.cn/scp/skill/...` 形式的公开链接。
4. 用无登录窗口打开一次，确认可访问。
5. 将该链接粘贴到赛事页“作品链接”。
6. 在“其他提交材料”上传 `QuantaForge_submission.zip`。

最终提交前确认：作品链接公开可访问、ZIP 根目录有 `SKILL.md`、GitHub 仓库公开、提交材料不含 SSH 密码或临时账号。
